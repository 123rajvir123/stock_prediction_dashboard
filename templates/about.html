About This Project

Advanced Stock Prediction Dashboard

PROJECT OVERVIEW

This project is a professional-grade web application built in Python using Flask that fetches live financial market data, tracks indices, calculates technical momentum indicators, and trains machine learning models to forecast the next closing price of any asset ticker.

Machine Learning Architecture

FORECASTING MODELS

The forecasting module trains and validates two distinct supervised learning algorithms on 1 year of historical market features (Open, High, Low, Close, Volume):

Linear Regression
BASELINE MODEL

Fits a linear combination of features to discover baseline trends in pricing, serving as an optimal benchmark.

Random Forest Regressor
ENSEMBLE MODEL

An ensemble decision tree model that captures non-linear relationships and interactions between volumes and price limits.

Chronological Split

To comply with financial machine learning best practices and prevent target leakage, the dataset is split chronologically (80% training, 20% validation). Models are fit on training data alone and verified against out-of-sample data.

Project Objectives

PROJECT GOALS

The objective of StockAI is to demonstrate full-stack proficiency in data science pipelines, real-time data ingestion, interactive browser storage APIs, and high-fidelity, responsive user interfaces.
